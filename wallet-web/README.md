# Страница «Сеть AYVIA» для веб-приложения

Отдельная страница `network.html`, которая добавляется к собранному приложению (папка `dist`
на Cloudflare) и работает с блокчейном AYVIA через `@ayvia/sdk`:

- подключение Keplr или Leap, либо кошелёк прямо в браузере (24 слова, шифрование паролем:
  PBKDF2 310 000 итераций + AES-GCM; фраза никуда не отправляется);
- баланс AYV, адрес, QR-код, перевод с комментарием;
- стейкинг у валидаторов, вывод из стейкинга, получение наград;
- история транзакций;
- графики: баланс по транзакциям, транзакции в блоке, время блока, доля стейкинга в сети;
- настройки адресов узла (⚙).

Проверено в браузере (headless Chrome) на тестовой сети: создание кошелька, пополнение,
перевод, стейкинг, награды, история, графики, QR, повторный вход по паролю, мобильная вёрстка.

## Сборка

```bash
npm install
npm run build          # -> dist/network.html, dist/network-config.js, dist/assets/ayvia-network-*.js
```

## Добавить в приложение

1. Скопировать содержимое `dist/` в папку собранного приложения (рядом с его `index.html`).
2. Добавить кнопку на главную: `python3 inject_link.py путь/к/index.html`.
3. Вписать публичные адреса узла в `network-config.js` (`rpc` и `rest`, только `https://`).
4. Загрузить папку в Cloudflare.

Адреса узла: если панель AYVIA открыта через туннель или домен `https://example`, то
`rpc` = `https://example/rpc`, `rest` = `https://example/rest`.
